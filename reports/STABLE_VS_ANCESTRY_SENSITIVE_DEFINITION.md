# Stable versus ancestry-sensitive retinal regulatory annotations

## Evidence available in Phase 0

HRCA Supplementary Table S12 provides the hg38 retinal major-cell OCR resource and Table S19 provides hg38 ancestry-associated DARs. The extracted S19 resource contains 2,228 DAR rows and 2,227 unique intervals across Rod, Cone, Bipolar, Amacrine, RGC, Müller glia and Horizontal classes. The S19 method in the HRCA supplementary material describes ancestry-based peak calling with MACS2 through ArchR, differential accessibility testing with Wilcoxon statistics normalized by TSS enrichment and log10 fragment counts, and marker-peak thresholds of FDR ≤ 0.05 and log2 fold change ≥ 0.5. Donor ancestry was decoded with ADMIXTURE using donor whole-genome sequencing data.

The current S19 labels are self-reported/author-defined ancestry labels in the table. They are retained verbatim; `African`, `East Asian` and `Admixed American` are not silently recoded into the GWAS ancestry labels.

## Definition options

1. **Primary stable set: matched non-DAR OCR controls.** Use the HRCA union OCR set from S12K, remove any interval overlapping an S19 ancestry-DAR interval, and match controls within cell class and, where available, width, GC and genomic annotation. This defines stability operationally as absence from the author-defined ancestry-DAR catalogue. It must be described as a non-DAR control definition, not proof of ancestry invariance.
2. **Primary ancestry-sensitive set: author-defined S19 DARs.** Use the S19 intervals with the reported FDR/log2FC thresholds and retain the cell-class and ancestry label. These intervals should be analyzed separately by East Asian, African and Admixed American labels; they should not be pooled as equivalent evidence of EUR/EAS divergence.
3. **Sensitivity set: all OCR minus DARs without matching.** This is useful for a broad annotation sensitivity analysis but is more vulnerable to cell-class, GC, width and genomic-background imbalance.
4. **Not available in the current resource audit: confidence-interval-defined stable regions.** S19 provides differential-accessibility statistics but no interval-level confidence interval suitable for a strict near-zero-effect definition. Non-significance must not be relabelled as stability.

## Recommended Phase 2 use

Use S19 as the ancestry-sensitive annotation and a cell-class-matched non-DAR OCR set as the stable comparator. Keep the global union-DAR analysis separate from cell-class analyses. Exclude RPE from primary HRCA S12/S19 analyses until an auditable RPE OCR resource is added; the current extracted S12/S19 sheet set does not provide an RPE row.

The exact matched control table and SNP-overlap counts are generated by the Phase 0 annotation QC script after the S12K union OCR extraction. All coordinate overlaps remain conditional until the GWAS build is resolved.
